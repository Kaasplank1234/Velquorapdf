# Velqora PDF 10.3

- Tools return to the left of the document. Page thumbnails open on the right.
- Dropdowns and number fields have continuous borders, attached arrow controls and a visible focus style.
- Dropdown items have more vertical space. Document tabs have a quiet close icon and elide long names in the middle.
- Scrollbars use the same design in light and dark modes.

The included workflow uses the baseline archive at the repository root and overlays the 10.3 source. On Linux, 16 unit tests, the launch smoke test and 71 in-app checks passed, including keyboard selection in the drawing dropdown. Big Sur 11.7.11 has not been verified. The macOS builds are not notarized.
