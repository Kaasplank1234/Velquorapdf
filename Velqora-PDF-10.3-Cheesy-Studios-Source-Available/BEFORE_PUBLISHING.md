# Before publishing Velqora PDF source

The original source archive includes an AGPL-3.0 license at `LICENSE`. This original license has been preserved. A proposed source-available license is included separately as `LICENSE-SOURCE-AVAILABLE-DRAFT.txt`, and an updated README as `README-PROPOSED.md`. **Neither draft replaces the currently included license.**

Before publishing, confirm you own the rights to relicense the applicable source files, check dependencies and third-party license obligations, and review for secrets and private data. The source package also contains a nested `Velqora-PDF-2.1-source.zip` (an older version), so confirm the 10.3 source is complete. If legally appropriate, rename the chosen license to `LICENSE` and the updated README to `README.md`.

To upload the source as separate files, extract this archive locally and use Git to push the project folder. Uploading this ZIP as a GitHub repository file will not unpack it automatically.
