# Velqora PDF 2.6

- Scroll continuously through pages. The page counter follows the visible page.
- Use Edit existing text and click a line, or double-click a line with Select. Type directly on the page. Enter applies the edit and Esc cancels it.
- Use Add text and click the page to place text.
- Select an annotation and press Delete, or right-click it and choose Delete annotation.
- Undo and Redo are visible in the document toolbar.
- Area-based operations such as crop and redaction still use a rectangle.
